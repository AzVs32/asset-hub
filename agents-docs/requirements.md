# 全新项目产品与软件需求入口

## 文档位置

PRD 与 SRS 草案位于 [doc/RPD&SRS.md](../doc/RPD&SRS.md)。涉及重新设计的产品范围、VFS 行为、两类插件、访问入口、权限边界或验收时，先读取该文档及相关条目。

## 适用范围与状态

- 该草案仅以项目负责人本次描述的目标为依据，作为全新项目的需求输入。
- 不从现有项目代码、架构、接口、错误规范或技术选型推导新项目要求。
- 需求的“已明确”“建议”“待决”状态见正文第 0.1 节；草案尚未成为开发基线。
- 未确认建议不能当作已经批准的需求；相关待决问题见正文第 13 节。
- 后续架构和模块契约以确认后的需求版本为输入；具体变更和验收关联使用正文中的编号。

本文件用于文档索引和范围说明；需求正文仅维护在上述文件中。
