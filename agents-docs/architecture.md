# 全新项目架构设计入口

总体架构讨论维护在 [doc/architecture.md](../doc/architecture.md)，输入为 [需求草案](../doc/RPD&SRS.md) 和 [技术选型](../doc/technology-selection.md)。涉及模块职责、依赖、运行流程、部署或插件边界时，读取相关文档和条目。

架构文档记录已明确的主项目/官方插件归属边界，以及当前 crate、依赖与验证计划。第 5～7 节用于模块和项目划分，第 8～10 节用于运行场景、AI 任务约束与验证。具体公共接口和插件执行机制仍待细化；未决方案不能当作已批准决定，新增方案需说明需求依据、选择理由与验证方法。

本文件仅提供主题入口；全新架构不继承现有项目实现和技术约定。
