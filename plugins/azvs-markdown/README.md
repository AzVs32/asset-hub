# AzVs Markdown Plugin

Extism + React plugin for Asset Hub Markdown document reading and editing.

## Files

- `manifest.json`: Asset Hub plugin manifest.
- `azvs-markdown.wasm`: compiled Extism plugin.
- `runtime`: Rust source for rebuilding the Wasm runtime.
- `web`: React reader/editor source loaded inside the host iframe.
- `dist`: deployable Web bundle generated from `web`.

## Contract

- Plugin ID: `azvs.markdown`
- Parent kind: `core:document`
- Read action: `azvs.markdown.render` (`render_markdown`)
- Edit action: `azvs.markdown.update` (`update_markdown`)
- Output view: `plugin_frame`

The action returns an Asset Hub `PluginView` frame payload:

```json
{
  "view": "plugin_frame",
  "title": "note.md",
  "url": "index.html#payload=..."
}
```

The Rust plugin reads Markdown content, returns a `plugin_frame` view, and handles writeback
through a `replace_content` effect. The frame URL is relative to the plugin web root; Asset Hub
resolves it to the public plugin asset route. The React UI uses `markdown-it` to render Markdown,
shows a title tree in read mode, and provides source editing with live preview in edit mode.

## Build

```bash
cargo build --locked --release --target wasm32-unknown-unknown \
  --manifest-path plugins/azvs-markdown/runtime/Cargo.toml
cp plugins/azvs-markdown/runtime/target/wasm32-unknown-unknown/release/azvs_markdown_plugin.wasm \
  plugins/azvs-markdown/azvs-markdown.wasm

cd plugins/azvs-markdown/web
npm ci
npm run typecheck
npm run build
cd ../../..
```

From the repository root, generate `manifest.lock.json` and validate Manifest V2:

```bash
cargo run -p asset-apps --bin asset-plugin -- \
  seal plugins/azvs-markdown/manifest.json
```

Lock digest values are generated by `asset-plugin seal` and must not be calculated or edited manually.
The root directory keeps the manifest, lock file, README, deployable wasm, and deployable web bundle consumed by Asset Hub.

Then add `plugins/azvs-markdown/manifest.json` to
`kind.plugin_manifests` in `config.toml`.
